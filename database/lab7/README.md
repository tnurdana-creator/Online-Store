# №7 зертханалық жұмыс - SQL SELECT сұраныстары

**Жоба:** Online-Store  
**Деректер қоры:** online_store_db  
**Бағдарлама:** PostgreSQL, pgAdmin 4

## Мақсаты

SQL SELECT сұраныстары арқылы деректерді алу, сүзгілеу, сұрыптау, топтау және талдау.

## Орындалған тапсырмалар

- SELECT және WHERE сұраныстары
- AND және OR шарттары
- DISTINCT және ORDER BY
- GROUP BY және HAVING
- COUNT, SUM, AVG, MIN, MAX функциялары

## Практикалық аналитикалық сұраныстар

1. Әр санаттағы тауарлар санын анықтау.
2. Орташа бағадан қымбат тауарларды анықтау.
3. Ең көп тапсырыс жасаған пайдаланушыларды анықтау.
4. Белгілі бір кезеңдегі тапсырыстар санын анықтау.
5. Тапсырыстардың жалпы сомасын анықтау.

## SQL файлы

## Қорытынды
