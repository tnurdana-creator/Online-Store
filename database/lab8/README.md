# №8 зертханалық жұмыс - Ішкі сұраныстар

**Жоба:** Online-Store  
**Деректер қоры:** online_store_db  
**Бағдарлама:** PostgreSQL, pgAdmin 4

## Мақсаты

JOIN, ішкі сұраныстар және CASE операторларын пайдаланып, деректер қорындағы мәліметтерді талдау.

## Орындалған тапсырмалар

1. JOIN арқылы бірнеше кестені біріктіру — 3 сұраныс.
2. Бір жолды, бір бағанды ішкі сұраныстар — 3 сұраныс.
3. Бірнеше жолды ішкі сұраныстар — 3 сұраныс.
4. CASE арқылы шартты мәндер қалыптастыру — 3 сұраныс.
5. Күрделі аналитикалық сұраныстар — 3 сұраныс.

**Барлығы: 15 SQL сұранысы.**

## Қолданылған кестелер

- `klient` — клиенттер.
- `tauar` — тауарлар.
- `tapsyrys` — тапсырыстар.

## SQL файлы

`lab8_onlinestore.sql` — зертханалық жұмыстың SQL сұраныстары.

## Қорытынды

Зертханалық жұмыс барысында JOIN, ішкі сұраныстар, IN, CASE, GROUP BY және HAVING қолданылды. Интернет-дүкендегі клиенттер, тауарлар және тапсырыстар туралы мәліметтер талданды.
