# №6 зертханалық жұмыс - Деректер қорын құру

**Жоба:** Online-Store  
**Деректер қоры:** online_store_db  
**Бағдарлама:** PostgreSQL, pgAdmin 4

## Мақсаты

SQL командалары арқылы деректер қорының кестелерін құру және мәліметтермен жұмыс істеу.

## Орындалған тапсырмалар

- Online-Store деректер қоры құрылды.
- 14 кесте жасалды.
- PRIMARY KEY және FOREIGN KEY қолданылды.
- INSERT арқылы мәліметтер қосылды.
- UPDATE арқылы мәліметтер өзгертілді.
- DELETE арқылы мәліметтер жойылды.

## SQL файлдары

- `create_tables.sql` - кестелерді құру.
- `data_operations.sql` - мәліметтерді қосу, өзгерту және жою.

## Қорытынды

Зертханалық жұмыс барысында Online-Store деректер қоры құрылып, SQL командалары арқылы кестелер мен мәліметтерге негізгі операциялар орындалды.
