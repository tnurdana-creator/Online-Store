# Use Case — Интернет-дүкендегі тапсырыс беру процесі

## Жүйе қатысушылары

1. Сатып алушы
2. Әкімші
3. Smart Order Assistant жүйесі

## Use Case 1: Тауарды таңдау

**Қатысушы:** Сатып алушы

**Сипаттамасы:**  
Сатып алушы интернет-дүкендегі тауарлар каталогын қарап, қажетті тауарды таңдайды.

**Негізгі қадамдар:**
1. Пайдаланушы тауарлар каталогын ашады.
2. Қажетті тауарды іздейді.
3. Тауардың өлшемін, түсін және моделін таңдайды.
4. Тауарды себетке қосады.

## Use Case 2: Тапсырысты тексеру

**Қатысушы:** Smart Order Assistant

**Сипаттамасы:**  
Тапсырыс рәсімделмей тұрып жүйе ықтимал қателерді автоматты түрде тексереді.

**Негізгі қадамдар:**
1. Сатып алушы «Тапсырыс беру» батырмасын басады.
2. Smart Error Check тапсырысты тексереді.
3. Жүйе қайталанған тауарларды анықтайды.
4. Жүйе өлшем, түс, модель және тауар саны параметрлерін тексереді.
5. Егер күмәнді жағдай анықталса, жүйе ескерту көрсетеді.
6. Клиент қатені түзетеді немесе өз таңдауын растайды.

## Use Case 3: Жеткізуді ұйымдастыру

**Қатысушы:** Smart Order Assistant

**Сипаттамасы:**  
Жүйе тауарлардың қай қоймаларда орналасқанын анықтап, жеткізуді оңтайландырады.

**Негізгі қадамдар:**
1. Жүйе себеттегі барлық тауарлардың орналасқан қоймаларын анықтайды.
2. Егер тауарлар әртүрлі қоймаларда болса, Smart Delivery Consolidation оларды талдайды.
3. Жүйе тауарларды мүмкіндігінше бір жеткізуге біріктіру жоспарын жасайды.
4. Клиентке жеткізу нұсқалары ұсынылады:
   - Барлығын бірге жеткізу;
   - Қолда бар тауарларды ертерек бөлек жеткізу.
5. Клиент қажетті жеткізу тәсілін таңдайды.

## Use Case 4: Тапсырысты рәсімдеу

**Қатысушы:** Сатып алушы

**Сипаттамасы:**  
Тексеруден кейін клиент тапсырысты растайды.

**Негізгі қадамдар:**
1. Клиент тапсырыс параметрлерін қарайды.
2. Қажет болса, қателерді түзетеді.
3. Жеткізу тәсілін таңдайды.
4. Тапсырысты растайды.
5. Жүйе тапсырысты қабылдайды.

## Use Case 5: Тауарларды басқару

**Қатысушы:** Әкімші

**Сипаттамасы:**  
Әкімші интернет-дүкендегі тауарлар каталогын басқарады.

**Негізгі қадамдар:**
1. Әкімші жүйеге кіреді.
2. Тауарлар бөлімін ашады.
3. Жаңа тауар қосады немесе бар тауарды өзгертеді.
4. Қажет болған жағдайда тауарды өшіреді.
5. Өзгерістерді сақтайды.

## Нәтиже

Smart Order Assistant көмегімен тапсырысты рәсімдеу процесі ыңғайлы және сенімді болады. Жүйе клиенттің ықтимал қателерін алдын ала анықтайды және әртүрлі қоймалардағы тауарларды мүмкіндігінше бір жеткізуге біріктіреді.
